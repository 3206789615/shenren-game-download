隐私政策第三方 SDK 与服务说明权限使用说明

Unity3D 游戏引擎

第三方名称：Unity Technologies；中国隐私说明所列主体为优三缔科技（上海）有限公司。引擎版本：Unity 2022.3.56f1c1。用途及场景：支撑游戏启动、图形渲染、音频播放和硬件适配。

信息类型与方式：引擎通过设备系统接口处理 AndroidID、设备型号、操作系统版本、CPU、内存、图形设备与屏幕参数。开发者业务代码不主动读取或上传 AndroidID，不将其用于广告跟踪。

时机及频次：仅在您同意后启动 Unity；相关设备接口由引擎启动和运行期间按需调用，实际频次由引擎实现及设备适配需要决定；游戏业务不按固定间隔轮询 AndroidID。

权限：引擎运行不以读取通讯录、定位、相机、录音或电话状态权限为前提。Unity Analytics 及其自动初始化已关闭，不启用 Unity Ads、内购及崩溃上报服务。

官网：https://unity.cn/。中国大陆隐私说明：https://unity.cn/public/legal/china-privacy-policy/。

GitHub 更新下载与网页服务

第三方名称：GitHub, Inc.。集成方式：HTTP 下载及网页链接，不是嵌入式登录或统计 SDK。用途：在您主动操作时检查版本、下载安装文件、查看公开网页。

信息类型与方式：服务器接收网络连接的 IP 地址、请求地址、请求时间及 HTTP 客户端技术信息；不在请求参数中附加本地存档、昵称或 AndroidID。时机与频次：每次您点击检查更新、下载或打开相应网页时；无后台定时轮询。权限：网络访问。

相关服务器可能位于境外；您可以不使用更新和外部网页功能，继续使用现有本地游戏。官网：https://github.com/。隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。
