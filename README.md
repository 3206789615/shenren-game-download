## 🖥️ 下载说明

### Android 版本
1. 下载 `.apk` 安装包
2. 在手机上允许安装未知来源应用
3. 安装后即可进入游戏体验

### Windows 版本
1. 下载 `.zip` 压缩包
2. 解压到本地文件夹
3. 运行对应的游戏程序即可开始体验
