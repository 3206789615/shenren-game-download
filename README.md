## 📝 更新日志

### v0.1.5

- 新增刀哥、丑橘、奶牛猫、泰迪、大运，补充武将技能与配音。
- 郝哥支持同时选择多个角色给瓜，或令多个有瓜角色摸牌、弃牌；场上无瓜时进入濒死，获救后按失去体力数补充新瓜。
- 恢复凑企鹅的蛊惑图标；拼点新增胜负动画，博弈在当前目标响应或受伤后揭晓。
- 优化技能台词播放时机，完善手机与电脑布局。
- 武将图鉴新增势力、已拥有与未拥有筛选，支持组合筛选、人数预览和重置。
- 完善选牌交互与倒计时，调整按钮和操作提示。
- 修复客户端台词试听及选将界面与项目运行不一致的问题。
- 游戏图标更换为耄耋（九命）的头部头像。
- 五谷选牌面板支持上下收放，收起后保留倒计时；统一选择界面的计时提示和演出层级。
- 补充七名新武将的聊天语音，修正嘉豪变身后的特效名称。
