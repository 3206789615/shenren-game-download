隐私政策第三方 SDK 与服务说明权限使用说明

本政策适用于《神人大乱斗杀》Windows、Android 本地游戏版本。游戏当前提供本机对局、角色养成和存档，不提供线上游戏账号、跨设备好友联机或云存档。请在决定是否同意前阅读本政策及相关说明；您可以在游戏设置中再次查看。

版本适用说明：本政策所述原生启动授权、关闭统计和手动更新安排适用于包含本政策的隐私整改版本，Android 内部构建号为 19 起。此前的 0.1.5 构建 18 不具备这些改动；网页更新不会自动修改您已安装的旧版本。

一、个人信息处理范围与目的

本地游戏档案。您创建存档、修改个人资料或进行游戏时，游戏在本机记录您设置的昵称、头像选择、角色与皮肤拥有情况、等级经验、虚拟道具、对局记录及剧情进度，用于保存进度和展示档案。信息由游戏直接写入本机应用存储，在相关操作和保存时更新；当前不会自动上传到开发者服务器。请勿以真实姓名、手机号或身份证号作为昵称。

本地偏好与授权记录。游戏在本机保存音量、显示、操作偏好、更新提示状态，以及您同意的政策版本和同意时间，用于保持设置、判断是否需要重新征询同意。仅在设置改变、更新检查或授权状态变化时写入；授权记录不使用设备标识符作为存储键。

Unity3D 引擎设备信息。Android 版本由 Unity3D 引擎运行。在您同意后启动引擎时，引擎通过设备系统接口读取 AndroidID（设备标识符），并处理设备型号、操作系统版本、CPU、内存、图形设备与屏幕参数，用于引擎运行、硬件与画面适配。相关信息在引擎启动及运行中按需处理；游戏业务不按固定间隔轮询 AndroidID。开发者业务代码不主动读取 AndroidID，不将其用于广告或跨应用跟踪；本版本关闭 Unity Analytics 及其启动初始化，不接入广告统计。引擎的主体和说明见第三方 SDK 与服务说明。

您主动检查或下载更新时的网络请求。点击游戏内“检查更新”“下载更新”或“打开下载页”后，客户端向 GitHub 请求版本清单或安装文件。连接会向网络服务方提供 IP 地址、请求地址、请求时间及 HTTP 客户端技术信息，用于传输、网络安全和下载服务；每次由您的相应操作触发，请求失败不妨碍现有本地游戏。开发者不在更新请求中附加昵称、存档或 AndroidID。相关服务提供方按其隐私声明处理网络记录。

您主动联系时提供的信息。发送邮件后，开发者处理您的邮箱地址、邮件内容及您选择附带的日志或截图，用于答复隐私请求和处理问题。请先遮盖截图中的个人敏感信息。请勿通过公开 GitHub Issues 提交私密资料。

二、启动告知与您的选择

Android 首次启动、清除授权记录或本政策发生需重新征询同意的变化时，先显示原生隐私告知页面。在您明确同意前，不启动 Unity 游戏引擎，不执行游戏更新检查，不申请安装更新权限。您可以先离线查看全部政策内容，也可以拒绝并离开告知页；查看、返回或切换后台不会被视为同意。

我们不以使用游戏为由要求同意广告、行为分析、定向推荐等非必要处理，这些服务当前不启用。系统权限的授权与隐私政策同意分别处理；您可以拒绝安装更新所需的系统设置，继续使用已安装版本。

三、第三方与系统权限

请查看第三方 SDK 与服务说明及权限使用说明。仅按本政策所述目的使用信息；不出售本地游戏档案，不把本地存档作为更新请求内容发送给第三方。当前未接入广告、第三方登录、支付、推送、云存档或个性化推荐服务。

GitHub 下载和网页访问可能连接境外服务器。该连接仅在您主动检查、下载或打开相应网络页面时发生。您可以不使用这些功能，继续体验已安装的本地内容。对相应平台独立处理的网络记录，可按其隐私声明向该平台提出请求。

四、保存期限与信息安全

本地档案和偏好保存至您删除相应存档、清除应用数据或卸载应用；设备备份与恢复行为以系统设置为准。授权版本记录保存至您撤回、清除应用数据或卸载。本版本禁用 Android 自动备份，减少本地授权记录被自动恢复的情况。游戏使用应用专属目录保存数据，不索取全盘文件访问权限。

隐私来信仅保留处理请求所需的内容和必要记录；处理完成后，除依法需要留存的情况外，于三十日内删除不再需要的附件和个人信息。第三方网络记录的保存期限以其政策为准。我们采取合理访问控制和最少处理措施，网络传输使用 HTTPS。

五、查阅、更正、删除与撤回

您可在游戏个人资料和存档管理中修改昵称、头像或删除存档；也可在系统应用设置中清除本地数据。删除和清除可能不可恢复，请确认后操作。开发者没有远程访问或恢复您本地存档的能力。

Android 游戏设置中的“隐私与权限”可再次查看本政策，并通过“撤回同意”清除本机授权记录。撤回后关闭当前游戏会话，下次启动重新显示告知页；撤回不删除您已有的本地存档。您也可联系邮箱提出个人信息查阅、复制、更正、删除、解释或投诉请求。

我们将在收到请求后十五个工作日内回复，并仅为核实和处理请求收集必要信息。涉及 GitHub 等第三方独立处理的信息，您也可以向其提出权利请求。

六、未成年人保护

未成年人应在监护人指导下阅读本政策和使用游戏。不满十四周岁的未成年人如涉及个人信息处理，应取得监护人同意；监护人可通过联系邮箱提出咨询、撤回或删除请求。请勿在邮件或公开反馈中发送未成年人身份证件资料。本政策不替代适用的游戏发行、实名及防沉迷要求。

七、政策更新与联系

新增联网、账号、云存档、广告、支付、SDK，或信息处理目的、方式和类型有实质变化时，我们会更新政策并按要求重新征求同意，不将旧版授权自动用于新增处理。
