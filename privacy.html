一、政策适用范围

本政策适用于《神人大乱斗杀》独立游戏试玩版本及其相关下载、版本检查和更新功能。游戏目前以本地人机对战为主；界面中的“好友房”等名称并不当然意味着已经提供跨设备联机服务。

本政策依据目前可核实的公开发行说明及项目源代码编写。后续若增加联网对战、用户账号、云存档、实名认证、广告、支付或新的第三方 SDK，开发者应在相应功能上线前更新本政策并依法履行告知、同意等义务。

二、我们处理哪些信息、用于什么目的

1. 本地游戏档案：当您创建或使用游戏存档时，游戏会在您的设备本地记录自行设置的游戏昵称、头像选择、角色/武将养成与拥有情况、对局记录、等级经验、游戏内虚拟道具、皮肤及剧情进度等，以便保存游戏进度和显示个人主页。这些数据主要写入应用本地存储空间中的 profile.json 等文件，不需要注册线上账号。

2. 本地配置：音量、界面显示、部分操作偏好及更新提示状态等设置可能保存在设备本地，用于维持您的使用习惯。

3. 版本检查和资源更新：游戏可能在启动时或您主动检查更新时访问 GitHub 上的更新清单及发布文件。为完成网络连接，服务提供方可能处理 IP 地址、请求时间、设备或客户端的必要技术信息。开发者目前未建立用于收集个人档案的自有在线账号服务器；上述网络连接信息可能由 GitHub 按其隐私政策处理。

4. 您主动反馈的信息：如果您通过 GitHub Issues 提交问题，您自愿提供的内容及 GitHub 账号公开信息会依照 GitHub 规则展示和处理。请不要在公开工单中发布身份证号码、手机号、家庭住址或其他敏感信息。

当前已核实的版本不要求用户以手机号、真实姓名或身份证号码注册游戏账号，也不以广告定向投放为目的主动收集个人信息。如实际安装包的行为与此描述不一致，须以发布前的实际功能审查结果为准并修订本政策。

三、设备权限

网络访问：用于检查、下载游戏版本或资源更新；不联网通常仍可体验已安装的本地游戏内容，但无法获取最新更新。

本地存储：用于保存、读取本机游戏档案和更新包；安装 Android 更新包时，可能需要您按系统提示确认安装或相关系统权限。

依据当前版本功能说明，游戏不以基础游玩为由要求读取通讯录、精确地理位置、摄像头或麦克风；武将台词与语音素材播放不等于采集麦克风音频。若未来新增相关功能，将在使用前说明。

四、信息保存期限与安全

游戏存档和配置一般保存在您自己的设备上，直至您主动删除、清理应用数据、卸载游戏或设备系统删除这些文件。Android 卸载或换签名重装可能导致本地存档丢失，请自行备份重要进度。

开发者不会为了提供当前离线游戏功能而将本地玩家档案自动同步到自建服务器。对更新下载、GitHub 页面访问等由第三方平台处理的信息，其保存期限与保护措施由相关平台的政策及适用法律确定。

我们将持续采用合理措施减少不必要的信息处理，但任何设备或网络环境都无法保证绝对安全。

五、第三方服务与跨境访问

游戏更新与公开下载使用 GitHub Releases／GitHub Pages 等服务；当您访问、检查或下载时，相关请求可能连接境外服务器，GitHub 可能依其政策处理网络访问数据。GitHub 隐私说明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

当前已核实的功能不以广告展示、第三方社交登录或商业统计为必要条件。是否存在其他随安装包分发的第三方 SDK、SDK 调用的数据类型及接收方，开发者应在正式发布前对 Android 安装包、依赖和实际网络请求进行复核；如有，应在本政策列出清单。

除法律要求或获得必要授权的情形外，我们不会主动出售您的游戏档案个人信息。

六、您的权利与本地数据管理

您可以在游戏中通过相关功能修改昵称等资料；删除或重置存档的具体操作以当前版本实际提供的界面为准。您也可以通过设备的应用数据管理删除本地记录，但请注意这可能不可恢复。

如需查阅、复制、更正、删除由开发者实际控制的个人信息，或咨询相关隐私事项，请通过下方联系渠道提出请求。对于保存在您设备上的本地档案，开发者通常无法远程查看或替您删除。

对于由 GitHub 等第三方独立处理的信息，您还可依据其隐私说明向相关平台提出权利请求。

七、未成年人保护

未成年人使用本游戏应在监护人指导下进行。涉及未成年人个人信息的处理时，我们将依适用法律采取额外保护措施；如今后提供实名认证、付费或在线服务，将按相应法律和监管要求增加适龄提示、防沉迷及其他必要机制。

本隐私政策不能替代游戏发行、版号、实名认证、防沉迷等适用法律法规要求。

八、政策变更

如游戏新增账号体系、联网、云存档、广告、支付、第三方 SDK 或处理信息的目的、类型和方式有实质变化，我们将及时更新本政策、明确更新日期，并按法律要求履行相关通知或同意义务。
